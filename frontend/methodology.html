System Methodology

Overview

This system leverages machine learning algorithms to automate the detection of seizure activities in EEG signals. By processing raw electrical activity from the brain, the platform identifies patterns associated with epileptic events, providing a streamlined workflow for research and academic analysis.

Step-by-step Workflow

1

Data Acquisition

EEG data is collected and stored as numerical features.

2

Upload

User uploads EEG data in CSV format.

3

Preprocessing

Data is validated, normalized, and standardized for model input.

4

Inference

Selected ML model analyzes the EEG patterns.

5

Result & Classification

System outputs binary seizure prediction with confidence scoring.

6

Grad-CAM Temporal Explainability

For 1D CNN predictions, gradient-weighted class activation mapping (Grad-CAM) highlights exact 1-second temporal segments driving seizure detection.

Models Evaluated

1D CNN + Grad-CAM

Deep Learning

Multi-stage 1D convolutional network with batch normalization and global average pooling. Fully interpretable via Grad-CAM temporal maps.

Bidirectional LSTM (BiLSTM)

Deep Learning

Recurrent neural network capturing forward and backward temporal dependencies across sequential EEG voltage points.

XGBoost

Gradient boosted decision trees yielding strong baseline tabular performance.

Random Forest

Ensemble method providing robust feature importance.

SVM (RBF Kernel)

Non-linear support vector machine mapping EEG features to high-dimensional space.

Logistic Regression

Baseline linear classifier for benchmark comparisons.

Decision & Explainability Logic

  • Binary Classification: Seizure vs. Non-Seizure (Class 1 vs Classes 2–5).
  • Confidence Scoring: Calibrated probability score mapped to Low (<70%), Medium (70–90%), and High (>90%) tiers.
  • Temporal Interpretability: Grad-CAM gradients backpropagated to the final Conv1D layer identify exact time intervals of paroxysmal EEG activity.
