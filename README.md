# SRM Epilepsy Project - EEG Seizure Detection System

A comprehensive machine learning platform for detecting epileptic seizures from EEG signals. This project combines a **FastAPI** backend for real-time inference with a modern **HTML/Tailwind CSS** frontend for visualization and analysis.

![Project Banner](https://img.shields.io/badge/Status-Active-success) ![Python](https://img.shields.io/badge/Python-3.9+-blue.svg) ![FastAPI](https://img.shields.io/badge/FastAPI-0.68+-green.svg) ![License](https://img.shields.io/badge/License-MIT-lightgrey.svg)

## 🌟 Key Features

*   **Multi-Model Analysis**: Utilizes **Logistic Regression**, **SVM (RBF Kernel)**, **Random Forest**, and **XGBoost** for robust seizure detection.
*   **Real-Time Inference**: Fast prediction on uploaded EEG CSV data files.
*   **Interactive Dashboard**: Clean, responsive UI for analyzing patient data and visualizing results.
*   **Model Comparison**: Dedicated tool to compare performance and confidence scores across all trained models.
*   **Robust Preprocessing**: Intelligent handling of raw EEG data, ensuring data integrity before analysis.
*   **Academic & Research Focus**: Designed for educational and research purposes with clear confidence metrics.

---

## 🏗️ Architecture

### Backend (`/backend`)
*   **Framework**: FastAPI (Python)
*   **Core Logic**:
    *   `app.py`: API routes for prediction (`/predict`) and comparison (`/compare`).
    *   `preprocess.py`: Robust data cleaning, validation (178 features), and standard scaling.
    *   `predict.py`: Model management and inference logic using `joblib` and `scikit-learn`.
*   **Models**: Pre-trained models stored in `models/` directory.

### Frontend (`/frontend`)
*   **Tech Stack**: Vanilla HTML5, Tailwind CSS (via CDN), JavaScript.
*   **Pages**:
    *   `index.html`: Landing page with project overview.
    *   `analysis.html`: Main dashboard for uploading EEG files and viewing predictions.
    *   `compare.html`: Comparative analysis tool.
    *   `methodology.html`, `datasets.html`, `team.html`: Informational pages.

## 🚀 Getting Started

### Prerequisites
*   Python 3.9+
*   pip
*   Git

### Installation

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/confuseddude/epiliepsy-project.git
    cd epiliepsy-project
    ```

2.  **Install Dependencies**
    ```bash
    pip install -r requirements.txt
    ```
    *(Note: If `requirements.txt` is missing, install key packages manually: `fastapi uvicorn pandas numpy scikit-learn xgboost joblib multipart`)*

3.  **Train Models (Optional)**
    If you want to retrain the models from scratch using `data/data.csv`:
    ```bash
    python train_models.py
    ```

### Running the Application

1.  **Start the Backend Server**
    ```bash
    uvicorn backend.app:app --reload
    ```
    The server will start at `http://127.0.0.1:8000`.

2.  **Access the Frontend**
    Open your browser and navigate to:
    [http://127.0.0.1:8000/index.html](http://127.0.0.1:8000/index.html)

## 📖 Usage Guide

1.  **Home**: Overview of the project mission.
2.  **Analysis**:
    *   Go to the **Analysis** page.
    *   Upload a CSV file containing EEG signal data (178 columns).
    *   Select a model (e.g., XGBoost) and click **Analyze EEG**.
    *   View the prediction (Seizure/Non-Seizure) and confidence score.
    *   Download the raw JSON results if needed.
3.  **Comparison**:
    *   Go to the **Comparison** page.
    *   Upload a CSV file.
    *   See how *all* models classify the same sample side-by-side.

## 📊 Dataset Information

The system is trained on the **UCI Epileptic Seizure Recognition Dataset**.
*   **Classes**:
    1.  Seizure Activity
    2.  Tumor Area (No Seizure)
    3.  Healthy Area (No Seizure)
    4.  Eyes Closed (Healthy)
    5.  Eyes Open (Healthy)
*   **Input Format**: Rows of 178 datapoints (1 second of EEG recording).
